📘 Student Form with Table & Validation – README
📌 Project Overview

This project is a Student Registration Form where users can enter student details and store them in a table below the form.

It includes basic validation and displays the entered data dynamically.

🛠️ Technologies Used
HTML5
CSS3
JavaScript
📂 Features
Input form for student details
Gender selection using radio buttons
Data displayed in a table after clicking Save
Basic validation for required fields
Clean and simple UI
🧾 Form Fields
Name
Age
Gender (Male / Female)
Course
Email
✅ Validation Rules
All fields must be filled
Age should be a number
Email should be in valid format (example@mail.com)
Gender must be selected
⚙️ How It Works
User enters details in the form
Clicks Save button
JavaScript validates inputs
If valid → data is added to the table
If invalid → error message is shown
